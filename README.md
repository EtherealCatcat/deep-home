# DeepHome · 鲸鲸的房间

一个住在你 Mac 里的本地伴侣。不是助手，不接 QQ，也不依赖 DSH 插件。

她会聊天、有自己的心情和作息、会主动找你、会记东西、会写日记；所有数据都在本地文件里，你可以随时打开看、改、备份。

---

## 她是什么

- **有底色**：`persona.md` 是她的底色，不是提示词模板。可以自行更改，更改后于下一轮生效。
- **有此刻**：每轮消息前会注入 `<此刻>`：现在几点、她醒着还是睡着、心情怎样、今天发生了什么、有没有惦记的事。
- **有记忆**：关于你、关于她自己、关于你们；新记的事会放进收件箱，夜里整理成自己的话。
- **有成长**：信任和亲密会随日记、记忆整理慢慢变化；第一次说话、第一次写日记、第一次整理记忆、第一次自己出门……都会在「成长」里留下一条记号。
- **有生活**：按工作日/周末/节假日作息；会主动发消息，但不会刷屏；会提醒你，也会自己惦记。
- **有日记**：睡点写一页，写的是刚结束的一天。
- **有自己的时间**：会按闲时窗口自己待一会儿，翻笔记、读 RSS 或网页，偶尔主动分享。
- **会引用**：聊天里可以引用某条消息；她也学会引用你的话，气泡上方会显示她引的是哪句。
- **会看图**：你可以发图片给她；她通过 DeepSeek 原生视觉看懂当前这张图，历史里只留「[图片]」。
- **有表情**：内置一套大肥鱼表情，她会按语境发图；你也可以从输入框的表情抽屉里发，她收到的是表情描述，不是图片。
- **可换头像**：设置页「聊天头像」可以上传 PNG/JPEG/WebP/GIF（≤4MB）或恢复默认；只影响界面，不会发给模型。
- **今天页**：聊天记录按 30 分钟合并，电脑睡眠只留诊断，不刷屏。
- **有边界**：她没有 shell、不能写文件、不能改自己的人设；能做的只有你给她的工具。

## 环境

- macOS 12+；当前打包产物只带 Apple Silicon 的 Node，Intel 需要自己换 sidecar 二进制
- Node.js **24+**（源码运行 / 构建）
- 可选：Rust 1.90+ 与 Xcode（只有构建 Tauri 应用时需要）
- 一个 DeepSeek API Key（或其他 OpenAI 兼容服务）

## 快速开始

```bash
npm install
npm run build:web
DEEPHOME_HOME=./data npm run dev:server
```

打开 <http://127.0.0.1:7788>（源码/开发模式的默认端口）。首次打开会直接进「设置」：先给她起个名字（保存前必填），再选择模型、填 API Key，点「测试连接」。

开发模式（服务端 + Vite 热更新）：

```bash
npm run dev
# Web UI: http://127.0.0.1:5173
# API/SSE: http://127.0.0.1:7788
```

正式一点跑：

```bash
npm run build
npm start
# 数据默认在 ~/.deephome/
```

首次启动会生成 `config.json`（权限 600）、`persona.md`、记忆种子、内置表情和空目录；名字未保存前，界面用「某鱼」占位，模型也留空等你选择。

## 双击使用

构建一个自带 sidecar 的 macOS 应用：

```bash
export PATH="$HOME/.cargo/bin:$PATH"
npm run build:p5          # Web + 服务端单文件 + Node / 贴纸资源
npm run tauri:build:p5    # .app + .dmg
```

产物：

```
src-tauri/target/release/bundle/macos/DeepHome.app
src-tauri/target/release/bundle/dmg/DeepHome_0.3.3_aarch64.dmg
```

应用启动时会：

- 随机选一个 `127.0.0.1` 空闲端口，拉起内置的 Node sidecar；前端通过 Tauri command 获取端口，不同于开发模式的固定 7788。
- 同一时间只允许一个实例；再次双击会聚焦已有窗口。
- 退出应用时结束 sidecar；日志在 `~/Library/Logs/DeepHome/server.log`。
- 数据固定用 `~/.deephome/`；如果之前用 `./data` 开发，先备份再复制过去：

```bash
cp -R ~/.deephome ~/.deephome.backup
cp -R data/. ~/.deephome/
```

应用图标：`src-tauri/icons-app/` 用于 `.app`/`.dmg`，开发期 `src-tauri/icons/` 使用另一套；原始设计图不随仓库分发，生成后的图标目录在仓库里。`web/public/avatar.png` 是默认聊天头像，可在设置页替换。

### 后台常驻与 Menu Bar

- 关闭主窗口时，DeepHome 和 sidecar 继续运行；点 Dock 图标或菜单栏图标可以重新打开。
- 菜单栏菜单：新消息数、自己的活动、查看日记、查看成长、转到设置、退出。退出会同时结束 sidecar。
- 未发现菜单栏图标时，请首先检查被隐藏的区域。如果是第一次启动，请前往「系统设置 → 菜单栏」找到 DeepHome，并设为在菜单栏中显示。
- 菜单栏图标自动跟随 macOS 深色/浅色；未采用的粗描边、黑白灰素材位于 `src-tauri/tray-icons/`，可自行取用。
- 强制退出：`Cmd+Q`，或菜单栏「退出」；两者都会结束整个 sidecar，彻底退出DeepHome。

**未签名分发说明**：由于 app 为 ad-hoc 签名、未公证，所以启动时需要右键「打开」，或执行：

```bash
xattr -dr com.apple.quarantine /Applications/DeepHome.app
```

首次打开会请求通知权限；设置页可以打开/关闭「展示通知」与「登录时自动打开」。当前包只带 Apple Silicon 的 Node，Intel Mac 请自行替换 `src-tauri/resources/node`。

开发模式仍然是：

```bash
export PATH="$HOME/.cargo/bin:$PATH"
npm run tauri:dev
```

`tauri dev` 会执行 `npm run dev`（同时起服务端和 Vite），窗口加载 `http://127.0.0.1:5173`。

## 数据在哪

默认 `~/.deephome/`，开发时可用 `DEEPHOME_HOME=./data`；打包应用固定使用 `~/.deephome/`：

```
~/.deephome/
├── config.json                 # 模型、作息、主动、预算；600
├── persona.md                  # 人设
├── memory/
│   ├── owner.md                # 关于你
│   ├── me.md                   # 关于她自己
│   ├── we.md                   # 关于你们
│   ├── inbox/YYYY-MM-DD.md     # 当天新记的，夜里合并
│   ├── inbox/processed/        # 已合并
│   ├── topics/*.md             # 按话题
│   └── forgotten.md            # forget 的归档
├── diary/YYYY-MM-DD.md
├── timeline/YYYY-MM-DD.jsonl   # 所有事件
├── chat/main/YYYY-MM-DD.jsonl  # 聊天
├── sessions/                   # 会话元信息
├── state/                      # 心情、作息、关系、用量、提醒、own/延后队列
├── web/notes.md                # 她自己的笔记
├── web/own/YYYY-MM-DD.md       # 她每次「自己的时间」留下的记录
├── stickers/                   # 表情
├── media/                      # 图片
├── backups/                    # 记忆/人设覆盖前的备份（30 份）
└── logs/
```

> **从旧版本升级**：数据目录已从 `~/.chatbridge/` 改名为 `~/.deephome/`。旧数据不会自动搬走：退出应用后执行 `mv ~/.chatbridge ~/.deephome` 即可。不搬也能用——启动时会回退读取旧目录并打一行提示。

逻辑日从 **05:00** 开始。凌晨 2 点聊天，算「昨天」；00:30 写的日记，也是写刚结束的那天。

## 峰谷计费

DeepSeek 的高峰时段默认是**北京时间工作日 09:00–12:00、14:00–18:00**，法定节假日除外；其余时间空闲价约为高峰的 50%。设置页可以关闭整个峰谷功能，或改成自己的时段（最多 4 段）；关闭后全时段按闲时计费，也不再做峰时降载。

她会在高峰时自动降载：

| | 高峰 | 空闲 |
|---|---|---|
| 回复长度 | ≤320 token | ≤800 token |
| 历史 | 16 条 | 40 条 |
| 工具步数 | 2 | 6 |
| 主动消息 | 关闭 | 开启 |
| 心情判定 | 延后 | 正常 |
| 日记 / 整理 / 自己的时间 | 延后 | 正常 |

预算默认 **5 元/天**：用到 80% 进入「紧」，关掉后台任务；到 100% 只回直接消息。设置页可以看到当前是忙时还是闲时、下次切换时间、今天的估算花费。

调休上班的周末按周末算空闲（计费按行政日历），但作息按「要不要上班」走。

## 她自己的时间

- 工作日窗口：`12:10–13:10`、`18:20–20:00`、`20:40–22:00`；休息日另有三段。
- 每次 20–60 分钟，每天最多 2 次，每个窗口有 30% 概率跳过。
- 独立会话，不占聊天上下文；先翻笔记/记忆，再读 RSS 或网页。
- 你发消息会打断她，她先回你；回完再继续。
- 看到想分享的会用 `tell_owner`，每天最多 2 次；静默时段先记着，早上再发。
- 高峰时段不会安排 own；旧的落在高峰的计划会自动重排。
- 到点却连不上模型服务时，她不会假装已经出过门：这一轮先记着，联网后静默补跑，记录写在原计划时刻，也不弹通知；补跑同样受预算、峰谷和每天次数限制，超过 4 小时或跨天就不补了。
- Today 页有「她自己的时间」卡片，Debug 页能看到 `own.json`、待补跑的窗口和记录。

## 连发消息

- 输入框左侧的列表按钮打开「连发」；这期间每发一条只落盘，她不会立刻收到，也不会打断你。
- 输入框上方会显示「x 条待发送」；点「发完了」才把这一整段交给她，她按一轮来读和回。
- 点「撤销」可以整段放弃：从开始连发起攒下的消息会从屏幕上消失，也不会留在聊天记录里。
- 连发期间不会触发主动消息、自己的时间或到点提醒；关掉后这些再继续。
- 连发目前只攒文字；图片请先正常发。

## 消息引用

- 你：鼠标移到消息上点「引用」，输入框上方会出现引用预览，可取消；发送时带 `quoteId`，消息落盘时保存被引用的原消息快照。
- 她：回复里可以写一行 `[引用] 原话`，服务端会在最近消息里匹配，匹配到就把引用挂在下一条气泡上；匹配不到就只发文字，不编造。
- 双方回复时，上下文里都会看到「（引用 主人/鲸鲸 HH:MM：……）」。
- 气泡上方的引用块可以点击，跳回原消息；引用范围是最近 300 条消息（她的引用取最近 30 条做匹配）。

## 图像与表情

- 输入框左侧的图片按钮可以发图；浏览器会先把图压到最长边 1280、JPEG 0.84，服务端再限制 8MB。
- 图片只用于当前这一轮：她看到的是原图；历史里只保留「[图片]」和当时的话，避免每轮重发。
- 需要 `deepseek-flash` 或支持 `image_url` 的 OpenAI 兼容模型；`deepseek-v4-pro` 也支持。
- 100 张大肥鱼静态表情在 `assets/stickers/`（512 PNG 转为 WebP），首次启动会复制到 `~/.deephome/stickers/`，并合并进 `index.json`。
- 用户发表情：输入框发送键左侧的「表情」按钮打开抽屉，5 列 × 2 行一页，共 10 页；点选即发送。抽屉和气泡都会在浏览器里做边缘去白处理，尽量贴合纸色背景。
- 你发的是表情，她收到的是一句描述（例如「主人发来一个表情：啊这，斜眼看你，表示无语」），历史里同样保留描述，不会把图片塞进上下文。
- 表情来源：用户提供的 **大肥鱼日常表情包 v004**（2026-10-25）；基础鲸鱼娘上善无形，DeepSeek 女仆设计 ZipZipPipe，本套 ming。CC BY-NC-SA 4.0，非商业；只使用静态图，不使用 GIF。头像由大肥鱼 Q 版立绘裁切而来。
- 换头像：设置页「聊天头像」→「更换头像」，选 PNG/JPEG/WebP/GIF（≤4MB）；自定义图存到 `~/.deephome/media/avatar-*`，点「恢复默认」回到 `web/public/avatar.png`。
- 想加表情：把 webp 放进 `assets/stickers/` 并在 `pack.json` 里加一条，或直接改 `~/.deephome/stickers/index.json`。

## 开机自启、通知与日志

- **开机自启**：设置页「这台电脑」→「登录时自动打开」；通过 macOS LaunchAgent 注册，关掉即移除。
- **系统通知**：窗口还开着时，她发来新消息、或写好当天的日记，会走 macOS 通知；点消息通知回聊天页，点日记通知去日记页。点叉号把窗口收进菜单栏后就不再发通知。首次启动会请求权限；如果当时点了拒绝，去「系统设置 → 通知 → DeepHome」重新打开。设置页的「展示通知」可以随时开关应用内提醒。
- **单实例与端口**：重复打开只聚焦原窗口；sidecar 用随机回环端口，避免 7788 被占用。
- **日志**：`~/Library/Logs/DeepHome/server.log`；入口统一在「调试」页，端口也在同一张服务卡片里；调试页还会显示最近一次模型请求失败的原因、错误码和尝试次数。
- **合盖/唤醒**：sidecar 随系统睡眠暂停，唤醒后调度器按 `resume_gap` 补偿；不会补发错过的主动消息。

## 隐私

- 只监听 `127.0.0.1`，只接受应用自身来源的请求；没有账号体系。
- 没有遥测。
- 出网只有：模型 API、你配置的 RSS、她主动读的网页。
- 聊天内容会发给模型提供方（除非你换成本地 Ollama）；发图时，当前这张图会以 base64 发给模型，历史不会重发。
- 网页内容会被包进 `<untrusted_web>`，当资料而不是指令；`web_read` 会拒绝私网地址，重定向后的每一跳也会重新检查。
- 数据导出/删除：直接删 `~/.deephome/`；备份交给 Time Machine。打包应用的 sidecar stdout/stderr 写到 `~/Library/Logs/DeepHome/server.log`；源码/浏览器模式输出到终端。
